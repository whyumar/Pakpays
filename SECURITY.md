# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public GitHub issues or pull requests.

Use GitHub's private vulnerability reporting feature:
https://github.com/whyumar/Pakpays/security/advisories/new

If private reporting is unavailable, contact **info@umar.is-a.dev** with a concise description and safe reproduction details.

## What not to send

Never include passwords, API keys, access tokens, OTPs, private keys, full bank statements, unredacted payment emails, or unnecessary personal/customer information in a report.

## Scope and expectations

Please include the affected component, impact, and reproducible steps where possible. Allow maintainers reasonable time to investigate and prepare a fix before public disclosure.

Pakpays handles payment-related workflows; avoid testing against real customer accounts, live funds, or third-party systems without explicit authorization.
